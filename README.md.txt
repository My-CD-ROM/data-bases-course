id (INTEGER)-Унікальний номер товару. PRIMARY KEY не дає повторювати ID, а AUTOINCREMENT автоматично підставляє +1 для кожного нового запису.
name та category (TEXT): Текстові поля для назви та категорії одягу (наприклад, "Худі").
size (TEXT): Розмір (наприклад, "M" або "42"). Зберігаємо як текст, бо з розмірами не проводять математичних розрахунків.
price (REAL): Ціна товару. Дійсне число, адже ціна має дробову частину з копійками (наприклад, 189.50).
stock_quantity (INTEGER): Кількість на складі. Тільки цілі числа, бо товар рахують штуками.

Навіщо потрібен Type Affinity
Хоча SQLite дозволяє запхати текст куди завгодно, правильні типи підказують базі, як обробляти дані. Якщо зберегти кількість як INTEGER, база зможе додавати й рахувати залишки. Якби ми дали тип ТEXT, то число 100 при сортуванні стало б меншим за 2, бо текст порівнюється по літерах, як у словнику, а не за числовим значенням.
