# Практична робота №22
## Тема: Створення процедур у PostgreSQL

### Мета роботи

Навчитися створювати та викликати збережені процедури PostgreSQL, використовувати параметри IN та OUT, виконувати перевірку вхідних даних за допомогою IF і RAISE EXCEPTION.

### 1. Створення процедури

Було створено процедуру `register_loan`, яка виконує дві операції: додає запис про видачу книги до таблиці `loans` та зменшує кількість примірників у таблиці `books`.

Процедура приймає два вхідні параметри: ID книги та ID читача.

**Результат:** процедуру успішно створено.

### 2. Перевірка роботи процедури

Для перевірки було використано книгу «Кобзар» (ID 1) та читача Олега Мельника (ID 2).

Після виклику `CALL register_loan(1, 2)` у таблиці `loans` з'явився новий запис з ID 12. Кількість примірників книги зменшилася з 8 до 7.

**Результат:** процедура працює правильно.

### 3. Перевірка неправильних викликів

Було перевірено два неправильні способи виклику:

- Виклик процедури через `SELECT` замість `CALL`. PostgreSQL повідомив, що для виклику процедури потрібно використовувати `CALL`.
- Виклик `CALL register_loan(1)` з недостатньою кількістю параметрів. PostgreSQL повідомив, що процедуру з такими аргументами не знайдено.

### 4. Додавання перевірки вхідних даних

Процедуру `register_loan` було оновлено за допомогою `CREATE OR REPLACE PROCEDURE`.

Додано перевірки:
- ID книги та читача не повинні бути NULL;
- книга повинна існувати;
- читач повинен існувати;
- кількість доступних примірників повинна бути більшою за нуль.

Для виведення повідомлень про помилки використано `RAISE EXCEPTION`.

Під час перевірки було виконано `CALL register_loan(999, 3)`. PostgreSQL вивів повідомлення «Книгу з ID 999 не знайдено».

Кількість неправильних записів у таблиці `loans` дорівнювала 0.

### 5. Створення процедури з параметром OUT

Створено процедуру `register_loan_with_id`, яка приймає два параметри IN та повертає ID створеної видачі через параметр OUT.

Для отримання ID використано конструкцію `INSERT ... RETURNING id INTO p_loan_id`.

Під час виклику `CALL register_loan_with_id(3, 4, NULL)` процедура повернула ID 14.

Після перевірки встановлено, що запис із ID 14 існує в таблиці `loans`, а кількість примірників книги «Місто» зменшилася з 4 до 3.

### 6. Перевірка режимів параметрів

За допомогою системного каталогу PostgreSQL `pg_proc` перевірено параметри процедур.

- `register_loan` — два параметри IN.
- `register_loan_with_id` — два параметри IN та один параметр OUT.

### 7. Порівняння з практичною роботою №14

У практичній роботі №14 розглядалися транзакції та забезпечення цілісності даних під час виконання декількох SQL-операцій.

У практичній роботі №22 створювалися збережені процедури, які об'єднують декілька операцій в один виклик, використовують параметри та перевіряють правильність вхідних даних.

Обидві теми допомагають забезпечувати правильність роботи бази даних.

### Висновок

Під час практичної роботи я навчилася створювати та викликати збережені процедури PostgreSQL, використовувати параметри IN та OUT, оновлювати процедури за допомогою CREATE OR REPLACE PROCEDURE та виконувати перевірку вхідних даних за допомогою IF і RAISE EXCEPTION.

Перевірила роботу процедур на прикладі видачі книг читачам. Усі заплановані перевірки виконано успішно.
