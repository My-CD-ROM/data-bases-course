Для id я вибрав тип INTEGER, тому що це номер кімнати, який має бути цілим числом і використовуватися як унікальний ідентифікатор.
Для type використав TEXT, тому що тут записується назва типу номера, наприклад «Стандарт» або «Люкс».
Для price_per_night вибрав REAL, тому що ціна може мати дробову частину. Наприклад, 1500.50.
Для capacity використав INTEGER, оскільки кількість людей у номері може бути тільки цілим числом.
Для status вибрав TEXT, тому що в цьому полі зберігається стан номера, наприклад «Вільний» або «Зайнятий».
Такі типи я вибрав відповідно до того, які дані будуть зберігатися в кожному стовпці. INTEGER підходить для цілих чисел, REAL для чисел із дробовою частиною, а TEXT для текстової інформації.
