# Практика 6. Команди UPDATE та DELETE у SQLite

## Завдання 2

UPDATE доречний, бо змінився лише телефон того самого клієнта: його `id` і зв'язок із замовленнями мають залишитися незмінними. Видалення старого рядка й вставка нового створили б нового клієнта, а через `ON DELETE SET NULL` замовлення старого клієнта втратили б посилання на нього (`client_id` став би `NULL`).

## Завдання 4

**Прогноз.** Для зовнішнього ключа `client_id` у Практиці 4 обрано `ON DELETE SET NULL`. Тому видалення клієнта з `id = 1` має пройти без помилки, а в замовленні `id = 1`, яке на нього посилалось, стовпець `client_id` має стати `NULL`. Саме замовлення не зникне (це не CASCADE), і видалення не буде відхилене (це не RESTRICT).

**Фактичний результат.** Перед виконанням було виконано `PRAGMA foreign_keys = ON;`. Команда `DELETE FROM clients WHERE id = 1;` виконалась без помилки. Після цього в таблиці `orders` залишився рядок з `id = 1`, у якого `client_id` дорівнює `NULL`, а в таблиці `clients` залишився лише клієнт з `id = 2`.

**Порівняння.** Фактичний результат збігся з прогнозом: `SET NULL` обнулив зовнішній ключ у пов'язаному замовленні, не видаляючи його.
