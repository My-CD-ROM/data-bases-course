# Лекція 12. Запити форматування таблиць (printf, дата й час)

*Дані в таблиці зберігаються в "сирому" вигляді: число `1234.5`, дата
`'2025-06-10'`. Але звіт часто потребує людяного формату: `1234.50
грн`, чи лише рік `2025` окремо від дати. SQLite надає функції прямо
всередині `SELECT`, що форматують значення "на виході" — без зміни
того, що фізично зберігається в таблиці.*

## 1. printf() — форматування чисел і рядків

```sql
SELECT amount, printf('%.2f грн', amount) AS formatted
FROM sales;
```

```text
amount   | formatted
1234.5   | 1234.50 грн
99.999   | 100.00 грн
```

`printf(шаблон, значення, ...)` — версія відомої функції `printf` з
мов C/Python прямо в SQL: `%d` — ціле число, `%.2f` — дійсне число з
рівно двома знаками після крапки (округлює, як видно з `99.999` →
`100.00`), `%s` — рядок. Усередині шаблону можна вільно змішувати
текст і плейсхолдери:

```sql
SELECT printf('%s - %d років', name, age) FROM animals;
-- 'Рекс - 5 років'
```

## 2. printf() — вирівнювання і нулі-заповнювачі

```sql
SELECT printf('%03d', 7);        -- '007'
SELECT printf('[%8.2f]', amount); -- '[ 1234.50]', '[  100.00]'
```

Число перед `d`/`f` у шаблоні — мінімальна ширина поля: `%03d`
доповнює зліва нулями до 3 символів, `%8.2f` доповнює пробілами
праворуч-вирівняного числа до ширини 8. Це особливо зручно для
рівних колонок у текстовому звіті.

## 3. Функції дати: date(), datetime(), поточний момент

```sql
SELECT date('now');       -- '2026-08-23'
SELECT datetime('now');   -- '2026-08-23 08:28:42'
```

SQLite зберігає дати як звичайний текст (`'2025-06-10'`), але має
вбудовані функції, що розуміють цей формат. `date('now')` і
`datetime('now')` повертають поточний момент — зручно для
`DEFAULT`-значень (Лекція 5) чи для порівняння з уже наявними датами.

## 4. Арифметика з датами через модифікатори

```sql
SELECT visit_date, date(visit_date, '+30 days') AS due_date
FROM visits;
```

```text
visit_date | due_date
2024-03-15 | 2024-04-14
```

Другий аргумент `date()`/`datetime()` — рядок-модифікатор
(`'+30 days'`, `'-1 month'`, `'+1 year'` тощо), що зсуває дату
відносно першого аргументу. Це рахує SQLite, а не студент вручну —
і безпечно враховує різну довжину місяців.

## 5. strftime() — витягти частину дати

```sql
SELECT visit_date,
       strftime('%Y', visit_date) AS year,
       strftime('%m', visit_date) AS month
FROM visits;
```

```text
visit_date | year | month
2024-03-15 | 2024 | 03
2025-01-20 | 2025 | 01
```

`strftime(формат, дата)` — найгнучкіша функція дати: за форматом
(`%Y` — рік, `%m` — місяць, `%d` — день, `%w` — день тижня від 0=нд)
витягує потрібну частину як **текст**. Це часто потрібно ПЕРЕД
`GROUP BY` (Лекція 9) — щоб згрупувати факти не за повною датою, а за
роком чи місяцем:

```sql
SELECT strftime('%Y', visit_date) AS yr, COUNT(*)
FROM visits
GROUP BY yr;
```

**Обережно з некоректним текстом у колонці дати:** якщо значення не
розпізнається як дата, `strftime()` (і решта функцій дати) мовчки
повертають `NULL`, а не помилку — перевірено:
`strftime('%Y', 'not-a-date')` → `NULL`. Це ще одна причина, чому
`CHECK`/формат дати варто перевіряти на вході (Лекція 5), а не
розраховувати, що функції дати самі підкажуть про помилкове значення.

## Підсумок

- `printf(шаблон, ...)` форматує числа й рядки для читабельного
  виводу — `%d` ціле, `%.2f` дійсне з фіксованою кількістю знаків,
  число перед специфікатором — мінімальна ширина поля.
- `date('now')`/`datetime('now')` дають поточну дату/час; другий
  аргумент-модифікатор (`'+30 days'` тощо) рахує зсув дати.
- `strftime(формат, дата)` витягує частину дати (рік, місяць, день
  тижня) як текст — зручно для `GROUP BY` за роком/місяцем.
- Функції дати на некоректному вхідному тексті мовчки повертають
  `NULL`, а не помилку — форматування не замінює перевірку даних на
  вході.
