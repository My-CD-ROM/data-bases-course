## Мета роботи

Навчитися створювати пов’язані таблиці SQLite, використовувати `JOIN`, `GROUP BY`, агрегатні функції `COUNT()` та `AVG()`, а також фільтрувати згруповані дані за допомогою `WHERE` і `HAVING`.

## Завдання 1. Створення таблиці відгуків

Створено таблицю `reviews`, яка зберігає відгуки покупців про товари. Вона містить такі поля:

* `id` — первинний ключ;
* `product_id` — зовнішній ключ товару;
* `rating` — оцінка від 1 до 5;
* `review_date` — дата відгуку;
* `comment` — текст відгуку.

Для поля `rating` встановлено обмеження `CHECK (rating BETWEEN 1 AND 5)`. Додано 8 відгуків для чотирьох товарів. Товар «Куртка Winter» не має відгуків.

## Завдання 2. Групування та середня оцінка

За допомогою `JOIN`, `GROUP BY`, `COUNT()` та `AVG()` отримано кількість відгуків і середню оцінку кожного товару.

| Товар          | Кількість відгуків | Середня оцінка |
| -------------- | -----------------: | -------------: |
| Футболка Basic |                  3 |           4,67 |
| Футболка Sport |                  2 |           3,50 |
| Джинси Classic |                  2 |           4,50 |
| Худі Urban     |                  1 |           3,00 |

## Завдання 3. Фільтрація через HAVING

Додано умову `HAVING AVG(r.rating) >= 4`.

Результат:

* Футболка Basic — 4,67;
* Джинси Classic — 4,50.

Умова `HAVING` залишила лише товари із середньою оцінкою не нижче 4.

## Завдання 4. Фільтрація за датою

Використано `WHERE r.review_date >= '2026-09-01'` разом із `JOIN`, `GROUP BY` та `HAVING`.

Результат:

| Товар          | Кількість відгуків | Середня оцінка |
| -------------- | -----------------: | -------------: |
| Футболка Basic |                  3 |           4,67 |
| Джинси Classic |                  2 |           4,50 |

Усі наявні відгуки відповідають заданому періоду, а умова `HAVING` відбирає товари із середньою оцінкою не нижче 4.

## Завдання 5а. Групування за ID та назвою

Додано товар із ID 6 та назвою «Футболка Basic», а також один відгук з оцінкою 5.

При групуванні за ID товари з однаковою назвою відображаються окремо:

* ID 1 — 3 відгуки, середня оцінка 4,67;
* ID 6 — 1 відгук, середня оцінка 5,00.

При групуванні лише за назвою ці товари об’єднуються:

* «Футболка Basic» — 4 відгуки, середня оцінка 4,75.

Отже, для розрізнення окремих товарів потрібно групувати за їхніми унікальними ID.

## Завдання 5б. Використання LEFT JOIN

Замість `JOIN` використано `LEFT JOIN`. Він дозволяє відобразити всі товари, навіть якщо вони не мають відгуків.

Товар «Куртка Winter» відображається з кількістю відгуків `0`, а середня оцінка має значення `NULL` (у Python — `None`).

## Завдання 5в. Висновок за результатами дослідження

Серед товарів із відгуками найвищу середню оцінку до додавання дубліката назви отримала «Футболка Basic» — 4,67, а «Джинси Classic» отримали 4,50. Після додавання нового товару з такою самою назвою групування за назвою об’єднує відгуки обох товарів, тому середня оцінка «Футболка Basic» становить 4,75.

## Контрольне питання

Якщо автор має дві книги, кожну з яких продано тричі, після з’єднання таблиць книг і продажів утвориться 6 рядків. `COUNT(*)` порахує рядки продажів, а не унікальні книги. Для підрахунку унікальних книг потрібно використати `COUNT(DISTINCT books.id)`.

## Висновок

Під час практичної роботи створено таблицю відгуків, пов’язану з товарами інтернет-магазину. Виконано групування даних, розрахунок кількості відгуків і середніх оцінок, фільтрацію за датою та середнім значенням. Досліджено відмінності між `JOIN` і `LEFT JOIN`, а також між групуванням за ID та назвою товару.
