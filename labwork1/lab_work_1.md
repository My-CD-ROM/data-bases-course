Практична робота 1

Для таблиці rooms були обрані такі типи даних:
Для поля id тип INTEGER, бо ідентифікатор це ціле число і являється порядковим номером. А PRIMARY KEY для кожної кімнати дає унікальне значення.

Для поля type я вибрав тип  TEXT, бо цей стовпець має в собі опис типу кімнати(люкс, стандарт і тд.), оскільки все це пишеться текстом, то йтип відповідний, бо є логічним для слів/назв.

Для поля price_per_night тип REAL, бо ціна може містити дробову частину - копійки. а даний тип є для чисел з рлаваючою комою.

Поле capacity має тип INTEGER, бо це місткість кімнати, і вона завжди є цілим числом.

Поле status визначає, вільна кімната чи зайнята, і ці дані записуються текстом, тому обраний тип TEXT.
