# Практична робота №8
## Застосування агрегатних функцій

Предметна область: Кінотеатр

### Завдання 1

Спочатку в таблиці `sessions` було 4 рядки і всі 4 мали значення `session_time`.

```text
COUNT(*) = 4
COUNT(session_time) = 4
```

Після цього один рядок було навмисно оновлено:

```sql
UPDATE sessions
SET session_time = NULL
WHERE id = 4;
```

Після оновлення:

```text
COUNT(*) = 4
COUNT(session_time) = 3
```

`COUNT(*)` рахує всі рядки таблиці, навіть якщо в них є `NULL`.

`COUNT(session_time)` рахує тільки ті рядки, де `session_time` не дорівнює `NULL`.

### Завдання 2

Для числової колонки `seats` таблиці `halls` виконано:

```sql
SELECT SUM(seats), AVG(seats)
FROM halls;
```

Результат:

```text
SUM = 330
AVG = 110.0
```

`SUM` показує загальну кількість місць у всіх залах кінотеатру.

`AVG` показує середню кількість місць в одному залі.

### Завдання 3

Для текстової колонки `title` виконано:

```sql
SELECT MIN(title), MAX(title)
FROM movies;
```

Результат:

```text
MIN = Інтерстеллар
MAX = Шрек
```

Для тексту `MIN` і `MAX` визначають значення за порядком сортування тексту. Тобто `MIN` повертає назву, яка стоїть першою за правилами порівняння тексту, а `MAX` — останню.

### Завдання 4

В одному запиті використано п'ять агрегатних функцій:

```sql
SELECT COUNT(*),
       SUM(hall_id),
       AVG(hall_id),
       MIN(session_date),
       MAX(session_date)
FROM sessions;
```

Результат:

```text
Кількість сеансів = 4
Сума id залів = 7
Середній id залу = 1.75
Найраніша дата = 2026-10-07
Найпізніша дата = 2026-10-08
```

Таким запитом можна отримати узагальнену статистику по всіх сеансах.

### Завдання 5

Для фільтрації використано жанр `Фантастика`:

```sql
SELECT COUNT(*) AS кількість_сеансів,
       AVG(hall_id) AS середній_id_залу,
       MIN(session_date) AS найраніша_дата
FROM sessions
JOIN movies ON sessions.movie_id = movies.id
WHERE movies.genre = 'Фантастика';
```

Результат:

```text
Кількість сеансів = 4
Середній id залу = 1.75
Найраніша дата = 2026-10-07
```

Результат змінився тому, що `WHERE` прибрав із розрахунку сеанс фільму жанру `Мультфільм`.

## Контрольні питання

### 1. Чому COUNT(*) і COUNT(колонка) можуть дати різні числа?

`COUNT(*)` рахує всі рядки, а `COUNT(колонка)` не враховує рядки, де ця колонка має `NULL`.

`COUNT(*)` і `COUNT(id)` зазвичай однакові, якщо `id` є первинним ключем, тому що первинний ключ не може мати `NULL`.

### 2. Якщо є 5 рядків і одне значення NULL, який знаменник буде в AVG?

Знаменник буде 4, тому що `AVG` ігнорує `NULL` і обчислює середнє тільки за ненульовими значеннями.

### 3. Що поверне SUM, якщо всі значення NULL?

`SUM` поверне `NULL`, а не 0 і не помилку.

Перевірка на базі:

```sql
SELECT SUM(x)
FROM (
    SELECT NULL AS x
    UNION ALL SELECT NULL
    UNION ALL SELECT NULL
);
```

Результат:

```text
NULL
```

## Висновок

У практичній роботі було застосовано агрегатні функції `COUNT`, `SUM`, `AVG`, `MIN` та `MAX`. Було перевірено вплив `NULL` на результати агрегатних функцій. Також було використано `WHERE`, який відфільтрував частину рядків до виконання агрегатного розрахунку.
