# Практична робота №2

## Варіант 2 — Інтернет-магазин одягу

### Завдання 1. SELECT

Запит вибирає стовпці name, category, size та price з таблиці products.

### Завдання 2. WHERE

Умова WHERE price > 500 вибирає товари, ціна яких більша за 500.

### Завдання 3. LIMIT

LIMIT 3 обмежує результат до трьох записів.

### Завдання 4. NULL

Для перевірки NULL було додано товар «Светр New», у якого значення category відсутнє.

Для пошуку порожніх значень використовується умова IS NULL.

Для пошуку заповнених значень використовується умова IS NOT NULL.

Порівняння через = NULL не працює, оскільки NULL означає відсутність або невідомість значення. Для перевірки NULL потрібно використовувати IS NULL або IS NOT NULL.

### Завдання 5. AND

Умова price > 500 AND stock_quantity >= 5 вибирає товари, які одночасно мають ціну більше 500 та кількість на складі не менше 5.

### Висновок

Під час практичної роботи було виконано вибір даних за допомогою SELECT, фільтрацію за допомогою WHERE, обмеження кількості записів за допомогою LIMIT, роботу з NULL за допомогою IS NULL та IS NOT NULL, а також використано логічний оператор AND.
