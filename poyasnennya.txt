Пояснення обраних типів SQLite

id — INTEGER PRIMARY KEY. Обрано INTEGER, тому що id є числовим ідентифікатором книги. PRIMARY KEY забезпечує унікальність кожного запису.

title — TEXT. Обрано TEXT, тому що назва книги є текстовою інформацією.

author — TEXT. Обрано TEXT, тому що ім'я та прізвище автора зберігаються у вигляді тексту.

publication_year — INTEGER. Обрано INTEGER, тому що рік видання є цілим числом, наприклад 1840 або 1944.

genre — TEXT. Обрано TEXT, тому що жанр книги записується словами, наприклад «роман», «поезія» або «історичний роман».

copies_count — INTEGER. Обрано INTEGER, тому що кількість примірників є цілим числом. Наприклад, у бібліотеці може бути 5 або 10 примірників.

У SQLite використовується type affinity. Тип стовпця визначає, як SQLite намагається зберігати значення. Для числових даних у нашій таблиці використовується INTEGER, а для текстової інформації — TEXT.
