# Практична робота №2
## Формування запитів вибірки у SQLite

### Завдання 4

Для перевірки відсутнього значення використано стовпець `group_name`. Один додатковий запис має значення `NULL` у цьому стовпці.

`IS NULL` знаходить записи, у яких значення відсутнє, а `IS NOT NULL` — записи, у яких значення присутнє.

Запис `group_name = NULL` використовувати неправильно, тому що NULL означає невідоме або відсутнє значення. Для його перевірки потрібно використовувати `IS NULL` або `IS NOT NULL`.

### Контрольні питання

**1. Чому `WHERE price = NULL` повертає порожній результат?**

NULL означає відсутність або невідоме значення. Порівняння через `=` з NULL не дає значення TRUE. Тому для перевірки потрібно використовувати `IS NULL`, наприклад `WHERE price IS NULL`.

**2. Чим `WHERE` відрізняється від `HAVING`?**

`WHERE` фільтрує окремі рядки таблиці до групування. `HAVING` фільтрує вже сформовані групи, зазвичай після `GROUP BY`.

**3. У якому випадку варто уникати `SELECT *` і чому?**

`SELECT *` варто уникати, коли потрібні тільки певні стовпці. Краще явно вказувати потрібні стовпці, щоб не отримувати зайві дані та зробити запит зрозумілішим.
