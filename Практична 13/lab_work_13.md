\## Завдання 1. printf() для числової колонки



Для форматування використано колонку `copies\_count` таблиці `books`.



Запит `printf('%d прим.', copies\_count)` виводить кількість примірників із додатковим текстом. Наприклад, сире значення `8` відображається як `8 прим.`. Так результат зрозуміліший для читача.



\## Завдання 2. printf() з вирівнюванням



Використано формат `printf('%5d', copies\_count)`, який задає мінімальну ширину поля п’ять символів. Це допомагає вирівнювати числа за шириною та полегшує їх порівняння.



\## Завдання 3. Зсув дати



За допомогою `date(loan\_date, '+7 days')` обчислено дату через сім днів після дати видачі книги. Це можна використати для визначення орієнтовної дати контролю повернення книги.



\## Завдання 4. strftime() і GROUP BY



За допомогою `strftime('%Y', loan\_date)` отримано рік видачі книг. Запит `GROUP BY year` підраховує кількість видач за кожен рік. У результаті за 2026 рік отримано 8 видач.



Групування за роком дає змогу об’єднати дати одного року, навіть якщо вони відрізняються днем або місяцем.



\## Завдання 5. Некоректна дата



Під час виконання `strftime('%Y', 'not-a-date')` і `date('not-a-date', '+7 days')` SQLite повернула `NULL`, а не повідомлення про помилку. Тому ці функції не можна використовувати як єдину перевірку правильності введених дат.



\## Контрольні питання



\*\*1. Чи змінює printf() значення в таблиці?\*\*



Ні. `printf()` лише форматує результат запиту. Значення, збережене в таблиці, не змінюється.



\*\*2. Чому strftime('%Y', ...) повертає текст?\*\*



Функція повертає текстове представлення року. Це потрібно враховувати під час сортування та порівняння значень.



\*\*3. Що означає результат для CHECK-обмежень?\*\*



Для перевірки дат потрібно використовувати додаткові умови, оскільки некоректна дата може дати `NULL`. Самого виклику функції дати недостатньо для надійної перевірки введення.



\## Висновок



Під час практичної роботи використано `printf()` для форматування чисел, `date()` для обчислення нової дати та `strftime()` для отримання року й групування записів. Також перевірено, що SQLite повертає `NULL` для некоректного тексту дати.
