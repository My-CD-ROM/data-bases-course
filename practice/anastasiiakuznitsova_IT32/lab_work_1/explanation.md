# Поясненя обраних типів даних
'id' - INTEGER PRIMARY KEY, тому що це унікальний числовий ідентифікатор кожного студента. Тип  INTEGER підходить для цілих чисел, а PRIMARY KEY забезпечує унікальність кожного запису.
'last_name' - TEXT, тому що прізвище складається з букв. Для цього стовпця SQlite використовує текстову type affinity.
'first_name' - TEXT, тому що і'мя складається з букв.
'group_name' - TEXT, тому що назва групи може містити і букви, цифри, символи.
'admission_year' - INTEGER, тому що рік вступу є цілим числом, а використання INTEGER дозволяє зберігати рік як значення, а не як текст.
