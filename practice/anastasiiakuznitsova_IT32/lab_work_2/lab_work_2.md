## Відповіді на питання

# NULL означає відсутність або невідомість значення. Порівняння через '= NULL' не повертає TRUE, тому рядок не проходить умову WHERE. Для перевідки NULL потрібно використовувати 'IS NULL', а для перевірки значення 'IS NOT NULL'.

# WHERE фільтрує окремі рядки таблиці до групуванняю HAVING фільтрує вже сформовані групи після групування.

# SELECT * варто уникати коли потрібні лише конкретні стовпці. Явний перелік стовпців робить запит зрозумілішим і дозволяє отримати тільки потрібні дані.
