# Відповіді на контрольні питання

## 1. Чому `WHERE price = NULL` завжди повертає порожній результат?

`NULL` означає відсутність або невідомість значення. При використанні `= NULL` результат порівняння не є `TRUE`, тому такий рядок не проходить умову `WHERE`. Для перевірки відсутності значення потрібно використовувати `IS NULL`, наприклад `WHERE price IS NULL`. Для перевірки наявності значення використовується `IS NOT NULL`.

## 2. Чим `WHERE` відрізняється від `HAVING`?

`WHERE` фільтрує окремі рядки таблиці до виконання групування. `HAVING` фільтрує вже сформовані групи після використання `GROUP BY`. Тому `WHERE` використовується для умов над окремими записами, а `HAVING` — для умов над групами.

## 3. У якому випадку варто уникати `SELECT *` і чому?

`SELECT *` варто уникати, коли потрібні лише конкретні стовпці таблиці. Краще явно вказувати необхідні стовпці, оскільки запит стає зрозумілішим, повертає менше непотрібних даних і не створює проблем при додаванні нових стовпців до таблиці.
