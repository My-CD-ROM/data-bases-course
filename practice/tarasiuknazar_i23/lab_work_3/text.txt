Таблиці:
 - cars
 - clients
 - sales

Зовнішні ключі (таблиця sales):
 - car_id -> cars.id
 - client_id -> clients.id

Типи зв'язку:
 - cars 1:N sales
 - clients 1:N sales

Первинні й зовнішні ключі кожної таблиці:
 - cars:
  - PK: id | FK: немає

 - clients:
  - PK: id | FK: немає

 - sales:
  - PK: id | FK: car_id -> cars.id / client_id -> clients.id

Таблиця завдання 4:

 managers(
     id,
     last_name,
     first_name,
     phone
 )

FK slaes: manager_id -> managers.id
managers 1:N sales



В обох схемах фактова таблиця має власний первинний ключ і два зовнішні ключі, які посилаються на дві вимірні таблиці. В обох випадках обидва зв'язки мають тип 1:N.
