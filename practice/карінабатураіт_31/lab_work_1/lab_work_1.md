Завдання 5. Обґрунтування обраних типів даних (Type Affinity)

У SQLite використовується гнучка типізація (Type Affinity). Для таблиці products обрано такі типи стовпців:

1. id (INTEGER PRIMARY KEY AUTOINCREMENT)
   - Унікальний ідентифікатор товару. Поєднання INTEGER PRIMARY KEY у SQLite зв'язує стовпець із внутрішнім rowid, що забезпечує автоматичну генерацію унікальних індексів та прискорює пошук.

2. name (TEXT)
   - Назва товару є текстовою строкою змінної довжини. Тип TEXT у SQLite підтримує кодування UTF-8, що дозволяє зберігати будь-які кириличні назви брендів чи моделей (наприклад, «Худі оверсайз KIKI»).

3. category (TEXT)
   - Категорія товару (наприклад, «Верхній одяг», «Штани») є якісною текстовою характеристикою для групування та фільтрації товарів.
4. size (TEXT)
   - Розмір одягу може містити як літерні (XS, S, M, L, XL), так і числові позначення (42, 44, 46). Щоб уніфікувати збереження різних форматів розмірів без втрати даних, обрано тип TEXT.

5. price (REAL)
   - Ціна товару передбачає наявність дробової частини (копійок). Тип REAL у SQLite використовується для збереження чисел із плаваючою крапкою, що дозволяє проводити математичні розрахунки суми, знижок та середнього чека.

6. stock_quantity (INTEGER)
   - Залишок товару на складі вимірюється в штуках і завжди є цілим додатним числом. Тип INTEGER займає мінімальний обсяг пам'яті та оптимізований для цілочисельних операцій.
