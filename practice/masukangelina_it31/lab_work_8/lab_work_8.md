Практична робота 8

Тема

Застосування агрегатних функцій.

Варіант

1 — Бібліотека.

Мета роботи

Ознайомитися з агрегатними функціями SQL COUNT, SUM, AVG, MIN, MAX та навчитися використовувати їх для отримання підсумкової інформації з таблиць бази даних.

Хід роботи

Завдання 1. COUNT та NULL

Було використано функцію COUNT(*) для підрахунку всіх записів у таблиці loans та COUNT(return_date) для підрахунку лише тих записів, де дата повернення заповнена.

Результат:

всього видач — 10;

повернення із заповненою датою — 6;

без дати повернення — 4.

COUNT(*) враховує всі рядки, у тому числі рядки, де значення окремих полів дорівнюють NULL. COUNT(return_date) не враховує NULL у полі return_date.

Завдання 2. SUM та AVG

Для таблиці books було визначено загальну та середню кількість примірників.

Результат:

загальна кількість примірників — 27;

середня кількість примірників — 3.85714285714286, або приблизно 3.86.

Функція SUM() обчислює суму числових значень, а AVG() — їх середнє арифметичне. Значення NULL при таких обчисленнях не враховуються.

Завдання 3. MIN та MAX

За допомогою MIN() та MAX() визначено межі дат видачі книг.

Результат:

найраніша дата видачі — 2026-09-10;

найпізніша дата видачі — 2026-09-17.

Функція MIN() повертає найменше значення, а MAX() — найбільше.

Завдання 4. Комбінація агрегатних функцій

В одному запиті було використано декілька агрегатних функцій для отримання загальної інформації про видачі книг.

Результат:

всього видач — 10;

повернених — 6;

перша видача — 2026-09-10;

остання видача — 2026-09-17.

Комбінація агрегатних функцій дозволяє отримати кілька підсумкових характеристик одним SQL-запитом.

Завдання 5. Агрегатні функції з умовою WHERE

Було повторено агрегатний запит і додано умову WHERE для таблиці-виміру books. Для аналізу вибрано книги жанру «роман».

Результат:

всього видач — 4;

повернення із заповненою датою — 3;

найраніша видача — 2026-09-10;

найпізніша видача — 2026-09-16.

У результат потрапили лише ті видачі, які пов'язані з книгами жанру «роман».

Відповіді на контрольні питання

1. Чим відрізняється COUNT(*) від COUNT(поле)?

COUNT(*) рахує всі рядки таблиці. COUNT(поле) рахує лише ті рядки, у яких вказане поле має значення, тобто NULL не враховується.

2. Як NULL впливає на AVG? Який знаменник?

AVG() не враховує значення NULL. Тому знаменником є кількість рядків, у яких поле має числове значення, а не загальна кількість рядків.

3. Що поверне SUM(), якщо всі значення NULL?

Якщо всі значення, які передаються у SUM(), дорівнюють NULL, функція поверне NULL, а не 0.

Висновок

Під час практичної роботи було опрацьовано агрегатні функції SQL COUNT, SUM, AVG, MIN та MAX. Було перевірено роботу цих функцій із NULL, визначено кількість видач книг, загальну та середню кількість примірників, а також найранішу і найпізнішу дати видачі. Додатково було використано JOIN та WHERE для отримання статистики тільки для книг жанру «роман».
