# Практична робота №1
## Створення бази даних у SQLite
### Варіант 1 — Бібліотека

## Таблиця books

### id — INTEGER PRIMARY KEY
Для поля `id` використано тип INTEGER, оскільки воно містить цілі числові значення. PRIMARY KEY визначає це поле як унікальний ідентифікатор кожного запису книги. Значення id дозволяє однозначно відрізняти один запис від іншого.

### title — TEXT
Для поля `title` використано тип TEXT, оскільки назва книги складається з текстових символів. Наприклад: «Кобзар», «Тигролови», «Місто».

### author — TEXT
Для поля `author` використано тип TEXT, оскільки ім'я та прізвище автора є текстовими значеннями. Наприклад: «Тарас Шевченко», «Іван Франко».

### publication_year — INTEGER
Для поля `publication_year` використано тип INTEGER, оскільки рік видання є цілим числом. Наприклад: 1840, 1944 або 1928.

### genre — TEXT
Для поля `genre` використано тип TEXT, оскільки жанр книги записується словами. Наприклад: «роман», «поезія», «драма».

### copies_count — INTEGER
Для поля `copies_count` використано тип INTEGER, оскільки кількість примірників є цілим числом. Наприклад: 3, 4, 5 або 6.

## Висновок

Під час практичної роботи було створено базу даних SQLite `lab_work_1.db` та таблицю `books`. До таблиці додано 6 записів про книги. Для текстових значень використано тип TEXT, для числових значень — INTEGER, а поле `id` визначено як PRIMARY KEY для ідентифікації записів.
