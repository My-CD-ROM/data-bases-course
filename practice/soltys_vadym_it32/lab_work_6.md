# Практика 6. UPDATE і DELETE у SQLite (варіант 2, інтернет-магазин одягу)

## Завдання 2
UPDATE доречний, бо змінюється лише поточний показник того самого товару (залишок `stock_quantity`), а сам товар і його `id` залишаються; видалення й повторна вставка дали б новий `id` і порушили б посилання на товар із таблиці `orders` (FK ON DELETE RESTRICT).

## Завдання 3
- `SELECT COUNT(*) FROM orders;` до видалення: **10**
- `DELETE FROM orders WHERE id = 10;`
- `SELECT COUNT(*) FROM orders;` після видалення: **9**

Зник рівно один рядок.

## Завдання 4
Видаляється клієнт `clients.id = 3` (Ірина Бондар), на нього посилаються замовлення `id = 4` і `id = 8`. У Практиці 4 для `orders.client_id` обрано `ON DELETE SET NULL`. `PRAGMA foreign_keys = ON;` увімкнено.

**Прогноз (до видалення):** рядок клієнта 3 буде видалено. Замовлення 4 і 8 залишаться в таблиці (загальна кількість замовлень лишиться 9), але їхній `client_id` стане `NULL`.

**Фактичний результат:**
- `SELECT * FROM clients WHERE id = 3;` повертає 0 рядків;
- замовлення 4 і 8 існують, `client_id = NULL` в обох;
- `SELECT COUNT(*) FROM orders;` = 9; усього рядків із `client_id IS NULL`: 2.

**Порівняння:** фактичний результат збігся з прогнозом. Розбіжностей немає.
