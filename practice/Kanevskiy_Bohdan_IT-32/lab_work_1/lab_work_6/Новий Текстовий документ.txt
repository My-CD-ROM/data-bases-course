Чим UPDATE ... SET колонка = колонка + 1 відрізняється від UPDATE ... SET колонка = <конкретне число>?
колонка = колонка + 1 змінює поточне значення, збільшуючи його на 1. колонка = конкретне число замінює поточне значення на вказане число.
Чому NOT NULL/UNIQUE/CHECK завжди перевіряються при UPDATE, а FOREIGN KEY — лише за умови PRAGMA foreign_keys = ON?
NOT NULL, UNIQUE і CHECK є вбудованими обмеженнями таблиці, тому SQLite перевіряє їх під час UPDATE. FOREIGN KEY у SQLite потрібно окремо увімкнути командою PRAGMA foreign_keys = ON;, інакше його перевірка не виконується.
Якби FK мав ON DELETE CASCADE замість RESTRICT, що змінилося б?
При ON DELETE CASCADE після видалення рядка з таблиці-виміру автоматично видалилися б усі пов'язані рядки з фактової таблиці. При RESTRICT видалення було б заборонене, якщо на цей рядок є посилання.
Чому DELETE без WHERE небезпечніший?
Тому що DELETE без WHERE видаляє всі рядки таблиці. Через помилку можна втратити всі дані, тоді як WHERE дозволяє видалити лише потрібні рядки.
