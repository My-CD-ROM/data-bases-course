Варіант 7 — Спортзал
Таблиця memberships

id — INTEGER PRIMARY KEY
Тип INTEGER обрано, тому що ідентифікатор абонемента є цілим числом. PRIMARY KEY забезпечує унікальність кожного запису.

type — TEXT
Тип TEXT обрано, тому що цей стовпець містить текстові назви абонементів, наприклад «Разовий», «Тижневий», «Місячний» або «Річний».

duration_days — INTEGER
Тип INTEGER використано для тривалості абонемента, оскільки кількість днів є цілим числом. Над цими значеннями можна виконувати числові операції.

price — REAL
Тип REAL обрано для ціни, оскільки вона може містити дробову частину. Наприклад, ціна може бути 150.50.

SQLite використовує поняття type affinity. Це означає, що тип стовпця визначає бажаний тип даних, але SQLite є гнучким щодо фактичних значень, які можна зберігати.
