int - INTEGER. Цей тип використано для унікального номера абонента. INTEGER підходить для цілих чисел, тому що ідентифікатор не потребує дробової частини.
type - TEXT. Цей тип використано для назви типу абонента, наприклад Basic, Premium або VIP. Оскільки це текстові значення, для них підходить TEXT.
duration_days - INTEGER. Цей тип використано для тривалості абонемента в днях. Кількість дніів є цілим числом, тому використання INTEGER є доцільним.
price - REAL. Цей тип використано для ціни абонемента. REAL підходить для числових значень, які можуть мати дробову частину, наприклад 499.99.
