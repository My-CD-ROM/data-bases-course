# Практика 17 - звіт (Варіант 6: Готель)

## Завдання 1
У файлі v6_raw_rows.csv 10 записів, роздільник крапка з комою. Наївний імпорт через .mode csv дав попередження на кожен запис, перші три:
- v6_raw_rows.csv:2: expected 4 columns but found 1 - filling the rest with NULL
- v6_raw_rows.csv:3: expected 4 columns but found 1 - filling the rest with NULL
- v6_raw_rows.csv:4: expected 4 columns but found 1 - filling the rest with NULL

Для запису "Стандарт, вид на парк" (рядок 10) попередження каже found 2, бо кома всередині значення розірвала його. COUNT(*) проміжної таблиці дорівнює 10, тобто виглядає правильно, але перша колонка першого рядка містить увесь запис: "Економ;850.0;1;вільний". Причина: режим CSV очікує кому, а файл із Excel використовує крапку з комою, тому SQLite не знайшов роздільників і поклав весь запис в одну колонку. Проміжну таблицю очищено через DELETE.

## Завдання 3
Знайдено три проблеми:
- Роздільник крапка з комою (Завдання 1).
- Порожнє поле capacity у записах "Мансарда" і "Апартаменти". Воно імпортується як порожній рядок, а не NULL (typeof = text для 2 рядків).
- Дублікат: номер "Економ" (850.0, 1, вільний) записаний двічі.

Розрахунок: 10 записів, мінус 1 дублікат, мінус 2 неповні рядки (колонка capacity у rooms має NOT NULL) = 7 рядків для перенесення.

## Завдання 4
До перенесення в rooms було 15 рядків (MAX(id) = 15). Пряме перенесення з NULLIF завершилось помилкою "NOT NULL constraint failed: rooms.capacity (19)", і вся команда не додала жодного рядка. Тому перенесено лише повні рядки (WHERE ... <> '') з DISTINCT. Після перенесення в rooms 22 рядки (MAX(id) = 22): приріст 7 збігається з розрахунком. Відкладено "Мансарда" і "Апартаменти" (немає значення capacity): значення вигадувати не можна, їх треба повернути власнику даних. Запит з IS NULL повернув 0 рядків, бо колонки rooms оголошені NOT NULL і NULL у них неможливий.

## Завдання 5
Вміст rooms_export.csv: рядок заголовків і 7 рядків з id 16-22. Роздільник кома (.mode csv повертає його після .separator ";"). Текстові значення SQLite бере в лапки, числа записує без лапок. Значення з комою записано як "Стандарт, вид на парк", тому кома його не розриває. NULL у файлі немає (колонки NOT NULL); якби він був, у файлі це було б порожнє поле. Якби такий файл імпортували назад, NULL повернувся б як порожній рядок, тому NULLIF знадобився б ще раз.
