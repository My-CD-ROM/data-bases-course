# Практика 16 - звіт (Варіант 6: Готель)

## Завдання 1
До імпорту в таблиці rooms було 7 рядків.

## Завдання 3
Після INSERT ... SELECT з проміжної таблиці й DROP TABLE в rooms стало 15 рядків. Приріст дорівнює 8, що точно відповідає кількості записів у CSV-файлі (без рядка заголовків).

## Завдання 4
Нові рядки отримали id 8, 9 і 15 (для економ, студіо і мансарда; решта нових рядків мають id з діапазону 8-15). Нумерація продовжила наявні id 1-7, а не почалась знову з 1: колонку id в INSERT не вказано, тому SQLite призначає наступний номер після найбільшого наявного.

## Завдання 5
Спроба .import безпосередньо в rooms (на тестовій копії бази) завершилась помилкою для кожного рядка: expected 5 columns but found 4 - filling the rest with NULL і INSERT failed: datatype mismatch. У CSV 4 колонки, а в таблиці 5: першою йде id INTEGER PRIMARY KEY. .import розкладає значення за порядком, а не за назвами заголовків, тому значення зсунулось на одну колонку: назва типу номера намагалась потрапити в id, куди можна записати лише ціле число. Жоден рядок не додався, COUNT(*) лишився 7.
