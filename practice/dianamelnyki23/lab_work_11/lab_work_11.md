## 2. Створення таблиці

Створено таблицю `visits` для збереження інформації про відвідування фітнес-клубу.

Таблиця містить такі поля:

- `client_id` — зовнішній ключ клієнта;
- `visit_date` — дата відвідування;

Для забезпечення цілісності даних використано первинний ключ, зовнішній ключ і обмеження `CHECK`. До таблиці додано 10 записів.

## 3. Завдання 2. Підрахунок відвідувань

## 4. Завдання 3. Використання HAVING

За допомогою `HAVING COUNT(v.id) >= 2` відібрано клієнтів, які відвідали фітнес-клуб щонайменше двічі.

Після додавання клієнта-тезки результат містить:

- Мельник Діана, ID 7 — 2 відвідування.

## 5. Завдання 4. Фільтрація за періодом

За допомогою `WHERE` відібрано відвідування за жовтень 2026 року. Умова `HAVING COUNT(v.id) >= 2` залишає клієнтів, які відвідали клуб щонайменше двічі протягом цього місяця.

Після додавання клієнта-тезки результат:

## 6. Завдання 5а. Групування за ID та за іменем

Для перевірки створено клієнта-тезку — Мельник Діану з ID 7 — та додано їй два відвідування.

Під час групування за `clients.id` клієнти з однаковими іменами залишаються окремими групами: ID 1 має 4 відвідування, а ID 7 — 2.

Під час групування лише за прізвищем та ім’ям їхні записи об’єднуються, тому загальна кількість відвідувань групи «Мельник Діана» становить 6.

Отже, для точного обліку необхідно групувати за унікальним ідентифікатором клієнта.

## 7. Завдання 5б. Використання LEFT JOIN

Запит із `LEFT JOIN` повернув ті самі три клієнти, що й запит із `JOIN`.

Причина полягає в тому, що умова `WHERE v.visit_date` відкидає рядки, у яких дата відвідування дорівнює `NULL`. Через це клієнти без відвідувань не з’являються у результаті, хоча використано `LEFT JOIN`.

## 8. Відповідь на дослідницьке питання

За результатами аналізу можна визначити клієнтів, які найчастіше відвідують фітнес-клуб. За весь період найбільше відвідувань має Мельник Діана, ID 1 — чотири. За жовтень 2026 року клієнти №1, №5 і №7 відвідали клуб по два рази.

Це дозволяє порівнювати активність клієнтів як за весь період, так і за окремий місяць.

## 9. Контрольне питання

Якщо автор має дві книги, а кожну книгу продали тричі, після об’єднання таблиць книг і продажів утвориться шість рядків. `COUNT(*)` порахує шість рядків продажів, а не дві книги. Щоб порахувати кількість унікальних книг, потрібно використати `COUNT(DISTINCT book_id)`.
