# Практична робота 6

## Робота з командами оновлення та видалення у SQLite

**Варіант 7 — Фітнес-клуб**


### Завдання 1. Оновлення запису у фактовій таблиці

У таблиці `membership_sales` оновлено дату завершення абонемента для запису з `id = 10`. Значення `expiration_date` змінено на `2026-10-11`.

Для визначення потрібного запису використано первинний ключ `id`.

### Завдання 2. Оновлення властивості у вимірювальній таблиці

У таблиці `memberships` змінено ціну студентського місячного абонемента з 800 до 850.

**Чому використано UPDATE, а не DELETE та INSERT?**

Команда `UPDATE` змінює конкретну властивість уже наявного абонемента, зберігаючи його ідентифікатор та зв’язки з іншими таблицями. Видалення та повторне додавання створили б зайву операцію й могли б порушити посилання з таблиці продажів.

### Завдання 3. Видалення одного запису

Перед видаленням у таблиці `membership_sales` було 10 записів. Видалено один запис із `id = 10`. Після видалення залишилося 9 записів.

Для видалення використано умову `WHERE id = 10`, щоб видалити лише один конкретний запис.

### Завдання 4. Перевірка зовнішнього ключа

У таблиці `membership_sales` поле `membership_id` посилається на `memberships(id)` із правилом `ON DELETE RESTRICT`.

Для абонемента з `id = 3` існують пов’язані записи продажів. Тому при ввімкненому `PRAGMA foreign_keys = ON` спроба видалити цей абонемент має завершитися помилкою зовнішнього ключа. Абонемент і пов’язані продажі повинні залишитися в базі.

### Контрольні запитання

**1. Чим відрізняється `SET column = column + 1` від `SET column = 10`?**

Перший вираз збільшує поточне значення стовпця на одиницю. Другий встановлює значення стовпця рівним 10.

**2. Які обмеження перевіряються під час UPDATE?**

Перевіряються обмеження `NOT NULL`, `UNIQUE`, `CHECK` та зовнішні ключі, якщо їх перевірку ввімкнено. Також можуть застосовуватися інші визначені для таблиці обмеження.

**3. Що робить ON DELETE CASCADE?**

Видалення батьківського запису автоматично видаляє пов’язані дочірні записи.

**4. Чому небезпечно виконувати DELETE без WHERE?**

Без умови `WHERE` команда видаляє всі записи таблиці. Це може призвести до втрати всіх даних у ній.

### Висновок

Під час практичної роботи відпрацьовано оновлення та видалення записів у SQLite. Перевірено зміну дати продажу, оновлення ціни абонемента, підрахунок записів до та після видалення, а також вплив правила `ON DELETE RESTRICT` на видалення пов’язаного абонемента.
