# Звіт до практичної роботи №8

## Тема

**Застосування агрегатних функцій SQL**

## Мета роботи

Навчитися використовувати агрегатні функції `COUNT`, `SUM`, `AVG`, `MIN`, `MAX` для отримання узагальненої інформації з бази даних, а також дослідити вплив значень `NULL` на результати агрегатних функцій.

## Варіант

**Варіант №1 — Бібліотека**

У роботі використовувалася база даних бібліотеки з таблицями `books`, `readers` та `loans`. Структура бази даних не змінювалася.

---

## Завдання 1. COUNT(*) проти COUNT(колонка)

Для таблиці `loans` було виконано запит:

```sql
SELECT
    COUNT(*) AS всього_позик,
    COUNT(return_date) AS позик_з_датою_повернення
FROM loans;
```

Результат:

* загальна кількість позик — **9**;
* кількість позик із датою повернення — **7**.

Отже, 2 записи мають значення `NULL` у колонці `return_date`. Функція `COUNT(*)` враховує всі рядки, а `COUNT(return_date)` не враховує рядки, де `return_date` має значення `NULL`.

**Скріншот:** результат виконання Завдання 1.

---

## Завдання 2. SUM і AVG

Було використано числову колонку `copies_count` таблиці `books`:

```sql
SELECT
    SUM(copies_count) AS загальна_кількість_примірників,
    AVG(copies_count) AS середня_кількість_примірників
FROM books;
```

Результат:

* `SUM` — **29**;
* `AVG` — **3.625**.

Загальна кількість примірників усіх книг становить 29. Середня кількість примірників однієї книги становить 3.625.

**Скріншот:** результат виконання Завдання 2.

---

## Завдання 3. MIN і MAX

Для визначення найранішої та найпізнішої дати видачі книг було використано:

```sql
SELECT
    MIN(loan_date) AS найраніша_дата_видачі,
    MAX(loan_date) AS найпізніша_дата_видачі
FROM loans;
```

Результат:

* найраніша дата — **2026-09-10**;
* найпізніша дата — **2026-09-18**.

Функція `MIN` визначає найменше значення дати, а `MAX` — найбільше. Для дат це відповідає відповідно найранішій та найпізнішій даті.

**Скріншот:** результат виконання Завдання 3.

---

## Завдання 4. Кілька агрегатних функцій в одному запиті

Було створено один запит, який одночасно використовує декілька агрегатних функцій:

```sql
SELECT
    COUNT(*) AS загальна_кількість_позик,
    COUNT(return_date) AS кількість_повернених,
    MIN(loan_date) AS найраніша_дата,
    MAX(loan_date) AS найпізніша_дата,
    COUNT(DISTINCT book_id) AS різних_книг
FROM loans;
```

Результат:

* загальна кількість позик — **9**;
* кількість позик із датою повернення — **7**;
* найраніша дата — **2026-09-10**;
* найпізніша дата — **2026-09-18**;
* кількість різних книг — **6**.

Запит дозволив отримати узагальнену інформацію про всі позики бібліотеки.

**Скріншот:** результат виконання Завдання 4.

---

## Завдання 5. Агрегат + WHERE

Для аналізу позик книг конкретного автора було використано умову `WHERE`:

```sql
SELECT
    COUNT(*) AS кількість_позик,
    COUNT(loans.return_date) AS кількість_повернених,
    COUNT(DISTINCT loans.book_id) AS різних_книг
FROM loans
INNER JOIN books
    ON loans.book_id = books.id
WHERE books.author = 'Тарас Шевченко';
```

Результат:

* кількість позик — **2**;
* кількість повернених — **1**;
* кількість різних книг — **1**.

Умова `WHERE` залишила для розрахунку тільки ті записи, які стосуються книг автора **Тарас Шевченко**. Тому агрегатні функції рахують не всі записи таблиці `loans`, а лише відібрані записи.

**Скріншот:** результат виконання Завдання 5.

# Контрольні питання

### 1. Чому COUNT(*) і COUNT(колонка) можуть повернути різні числа?

`COUNT(*)` рахує всі рядки таблиці, незалежно від значень у колонках. `COUNT(колонка)` рахує тільки ті рядки, де відповідна колонка не має значення `NULL`.

`COUNT(*)` і `COUNT(id)` зазвичай дають однаковий результат, якщо `id` є первинним ключем і не може містити `NULL`.

### 2. Який знаменник використовується в AVG, якщо одне з п'яти значень дорівнює NULL?

Знаменник дорівнюватиме **4**, тому що `AVG` не враховує значення `NULL` під час обчислення середнього значення.

### 3. Що поверне SUM, якщо всі значення колонки дорівнюють NULL?

У SQLite функція `SUM` у такому випадку повертає **NULL**, а не 0 і не помилку.

# Висновок

Під час виконання практичної роботи було застосовано агрегатні функції `COUNT`, `SUM`, `AVG`, `MIN` та `MAX` до таблиць бібліотечної бази даних.

Було встановлено, що `COUNT(*)` враховує всі рядки, а `COUNT(колонка)` ігнорує значення `NULL`. За допомогою `SUM` та `AVG` було визначено загальну та середню кількість примірників книг. Функції `MIN` і `MAX` дозволили визначити найранішу та найпізнішу дату видачі книг.

Також було використано декілька агрегатних функцій в одному запиті та досліджено роботу агрегатів разом з `WHERE`. Практична робота показала, що `WHERE` спочатку відбирає потрібні рядки, а вже після цього над ними виконуються агрегатні функції.
