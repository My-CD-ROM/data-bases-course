## Мета роботи

Навчитися використовувати оператор `GROUP BY` для групування даних, застосовувати агрегатні функції, виконувати групування після `JOIN`, а також дослідити особливості роботи SQLite зі стовпцями, які не входять до `GROUP BY`.

## Хід роботи

### Завдання 1. GROUP BY за одним стовпцем

Для кожної книги було визначено кількість позик за допомогою `GROUP BY book_id` та `COUNT(*)`.

Отримано:

* книга 1 — 2 позики;
* книга 2 — 2 позики;
* книга 3 — 2 позики;
* книга 4 — 1 позика;
* книга 5 — 1 позика;
* книга 6 — 1 позика.

**Висновок:** групування за одним стовпцем дозволяє отримати окремий підсумок для кожної книги.

**Скріншот:** результат виконання завдання 1.

### Завдання 2. JOIN + GROUP BY

Було виконано `LEFT JOIN` таблиць `books` і `loans` та проведено групування за ідентифікатором книги.

Результат:

| Книга            | Кількість позик |
| ---------------- | --------------: |
| Кобзар           |               2 |
| Тигролови        |               2 |
| Місто            |               2 |
| Захар Беркут     |               1 |
| Лісова пісня     |               1 |
| Чорна рада       |               1 |
| Тестова книга    |               0 |
| Книга без видачі |               0 |

Використання `LEFT JOIN` дозволило показати також книги, які не мають жодної позики.

**Скріншот:** результат виконання завдання 2.

### Завдання 3. Кілька агрегатних функцій

До запиту було додано ще одну агрегатну функцію — `AVG()` для визначення середньої кількості примірників книги.

Результат:

| Книга            | Позики | Примірників |
| ---------------- | -----: | ----------: |
| Кобзар           |      2 |           5 |
| Тигролови        |      2 |           3 |
| Місто            |      2 |           4 |
| Захар Беркут     |      1 |           6 |
| Лісова пісня     |      1 |           4 |
| Чорна рада       |      1 |           6 |
| Тестова книга    |      0 |           0 |
| Книга без видачі |      0 |           1 |

**Висновок:** у межах одного групування можна використовувати декілька агрегатних функцій.

**Скріншот:** результат виконання завдання 3.

### Завдання 4. GROUP BY за двома стовпцями

Групування було виконано одночасно за `reader_id` та `book_id`.

У результаті отримано **9 рядків**. Кожна комбінація читача та книги зустрічається один раз, тому для кожної групи кількість позик дорівнює 1.

**Висновок:** групування за двома стовпцями формує групи за унікальними комбінаціями значень цих стовпців.

**Скріншот:** результат виконання завдання 4.

### Завдання 5. Стовпець поза GROUP BY

Було виконано запит, у якому `loan_date` вибирається, але не входить до `GROUP BY` і не є агрегатною функцією.

SQLite дозволив виконати такий запит. Під час двох запусків значення `loan_date` залишилися однаковими:

* книга 1 — `2026-09-10`;
* книга 2 — `2026-09-11`;
* книга 3 — `2026-09-12`;
* книга 4 — `2026-09-13`;
* книга 5 — `2026-09-14`;
* книга 6 — `2026-09-15`.

Однак таке значення не є гарантованим, оскільки SQLite може взяти значення з одного з рядків відповідної групи.

У PostgreSQL подібний запит буде відхилено, оскільки `loan_date` не входить до `GROUP BY` і не використовується в агрегатній функції.

**Висновок:** необхідно дотримуватися правил `GROUP BY` та не використовувати неагреговані стовпці поза групуванням.

**Скріншот:** результати першого та другого запуску завдання 5.

У результаті було отримано практичні навички формування групованих SQL-запитів та аналізу отриманих результатів.
