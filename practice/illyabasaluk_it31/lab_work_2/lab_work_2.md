# Практична робота №2

## Формування запитів вибірки у SQLite

### Мета роботи

Навчитися формувати SQL-запити для вибірки даних із таблиці SQLite за допомогою `SELECT`, `WHERE`, `LIMIT`, `IS NULL`, `IS NOT NULL` та складених умов.

### Завдання 1. SELECT з явним переліком стовпців

Для вибірки даних із таблиці `books` було використано явний перелік стовпців:

```sql
SELECT title, author, publication_year, genre
FROM books;
```

Запит виводить назву книги, автора, рік видання та жанр.

### Завдання 2. WHERE

Для фільтрації книг за роком видання використано умову:

```sql
SELECT title, author, publication_year, genre
FROM books
WHERE publication_year > 1900;
```

Запит виводить книги, видані після 1900 року.

### Завдання 3. LIMIT

Для обмеження кількості результатів використано:

```sql
SELECT title, author, publication_year, genre
FROM books
LIMIT 3;
```

Запит виводить лише перші три записи таблиці.

### Завдання 4. IS NULL та IS NOT NULL

Для перевірки наявності значення `NULL` було додано книгу, у якої поле `genre` має значення `NULL`.

Для пошуку записів із `NULL` використано:

```sql
SELECT title, author, genre
FROM books
WHERE genre IS NULL;
```

Для пошуку записів, де значення не є `NULL`:

```sql
SELECT title, author, genre
FROM books
WHERE genre IS NOT NULL;
```

`NULL` не можна перевіряти за допомогою `= NULL`, оскільки `NULL` означає відсутність або невідомість значення. Для перевірки потрібно використовувати `IS NULL` або `IS NOT NULL`.

### Завдання 5. Складена умова

Для одночасної перевірки двох умов використано оператор `AND`:

```sql
SELECT title, author, publication_year, copies_count
FROM books
WHERE publication_year > 1900
  AND copies_count > 3;
```

Запит знаходить книги, які видані після 1900 року та мають більше 3 примірників.

### Контрольні питання

**1. Чому `WHERE price = NULL` повертає порожній результат? Що потрібно використовувати замість цього?**

`NULL` означає відсутність або невідомість значення, тому його не можна порівнювати через оператор `=`. Для перевірки потрібно використовувати `IS NULL`, а для перевірки наявності значення — `IS NOT NULL`.

**2. У чому різниця між WHERE та HAVING?**

`WHERE` фільтрує окремі записи
