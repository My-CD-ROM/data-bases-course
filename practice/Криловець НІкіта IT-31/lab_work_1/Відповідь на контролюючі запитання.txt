1. Чому SQLite називають файловою, безсерверною СУБД — і що це означає на практиці?
SQLite не потребує окремого сервера. Вся база даних зберігається в одному файлі, наприклад file.db, який можна переносити або копіювати.

2. Яка різниця між роботою через sqlite3 (CLI) і через DB Browser for SQLite?
sqlite3 працює через термінал і зручний для виконання SQL-команд. DB Browser має графічний інтерфейс і зручніший для перегляду та редагування таблиць.

3. Що таке type affinity в SQLite і чим вона відрізняється від PostgreSQL?
Type affinity означає, що SQLite не так суворо контролює типи даних у стовпцях. У PostgreSQL типи стовпців контролюються набагато суворіше.

4. Чим id INTEGER PRIMARY KEY відрізняється від звичайного INTEGER?
PRIMARY KEY робить id унікальним ідентифікатором рядка. Звичайний INTEGER може містити однакові значення.
