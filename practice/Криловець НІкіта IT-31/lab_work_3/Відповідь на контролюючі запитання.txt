1. Чому SQLite називають файловою, безсерверною СУБД?
SQLite не потребує окремого сервера. Уся база даних зберігається в одному файлі .db або .sqlite, який можна легко перенести на інший комп'ютер.

2. Різниця між sqlite3 і DB Browser for SQLite
sqlite3 — це консольний інструмент, де SQL-запити вводяться через термінал. Зручний для командного рядка.
DB Browser — це графічна програма, у якій зручніше переглядати таблиці, дані та виконувати запити.

3. Що таке type affinity?
Type affinity — це система SQLite, яка дозволяє більш гнучко зберігати різні типи даних у стовпцях.
У PostgreSQL типи суворіші: наприклад, у INTEGER не можна записати текст.

4. Чим id INTEGER PRIMARY KEY відрізняється від INTEGER?
INTEGER — звичайний стовпець для цілих чисел.
INTEGER PRIMARY KEY — унікальний ідентифікатор рядка. У SQLite його значення може автоматично збільшуватися при додаванні нових записів.
