    Практика 15. Імпорт даних із CSV у SQLite¶

    Мета заняття: застосувати техніку з Лекції 16 — імпортувати готовий CSV-файл із додатковими рядками у свою таблицю-вимір 1 через проміжну (staging) таблицю, оскільки пряме .import в таблицю з id не працює.

    Файл із новими рядками для вашого варіанта¶

    Нижче — по одному CSV-файлу на кожен із 10 варіантів: 8 нових реалістичних рядків для таблиці-вимір 1 вашого варіанта (ті самі колонки, що в таблиці, без колонки id — SQLite призначить її сама, як і в Лекції 16). Це не "відповідь" практики — це лише вхідний файл, який належить ІМПОРТУВАТИ; сам імпорт (проміжна таблиця, INSERT ... SELECT, перевірка результату) — ваше завдання:

    • v1_new_rows.csv — Бібліотека (books)
    • v2_new_rows.csv — Інтернет-магазин одягу (products)
    • v3_new_rows.csv — Кінотеатр (movies)
    • v4_new_rows.csv — Аптека (medicines)
    • v5_new_rows.csv — Автосалон (cars)
    • v6_new_rows.csv — Готель (rooms)
    • v7_new_rows.csv — Спортзал (memberships)
    • v8_new_rows.csv — Служба доставки їжі (dishes)
    • v9_new_rows.csv — Університет (courses)
    • v10_new_rows.csv — Транспортна компанія (drivers)

    Якщо власна база з попередніх практик втрачена — поверніться до v{N}_prerequisites.sql Практики 4 (чи більшого набору з Практики 14, якщо він зручніший) і продовжуйте цю практику на ній.

    Приклад: наскрізна демонстрація¶

    -- new_animals.csv
name,species,age,status
Джек,собака,2,на обліку
Соня,кіт,4,на обліку

    CREATE TABLE animals_staging (
    name TEXT, species TEXT, age INTEGER, status TEXT
);

    .mode csv
.import --skip 1 new_animals.csv animals_staging

    INSERT INTO animals (name, species, age, status)
SELECT name, species, age, status FROM animals_staging;

DROP TABLE animals_staging;

SELECT COUNT(*) FROM animals;  -- перевірка: стало більше на 2

    Завдання¶

    Завдання 1. Підрахунок ДО імпорту. Виконайте SELECT COUNT(*) FROM таблиця_вимір_1; і зафіксуйте письмово точне число рядків, яке було у вашій таблиці-вимір 1 ДО імпорту.

    Завдання 2. Проміжна таблиця й імпорт CSV. Створіть проміжну таблицю з колонками, що точно відповідають заголовкам CSV-файлу вашого варіанта (без id), і імпортуйте файл у неї через CLI (.mode csv + .import --skip 1 ...) або майстер імпорту DB Browser for SQLite. Перевірте вміст проміжної таблиці окремим SELECT.

    Завдання 3. Перенесення в реальну таблицю. Виконайте INSERT ... SELECT із проміжної таблиці у вашу справжню таблицю-вимір 1, а потім видаліть проміжну таблицю (DROP TABLE). Виконайте SELECT COUNT(*) ще раз і письмово підтвердьте: різниця з числом із Завдання 1 дорівнює точно 8 (кількості рядків у CSV-файлі).

    Завдання 4. Перевірка конкретних нових рядків. Складіть запит (WHERE ... IN (...) чи LIKE, Лекція 11), що знаходить у таблиці саме ті рядки, які прийшли з імпортованого CSV (за назвою/значенням, якого не було раніше). Письмово підтвердьте, що їхні id природно продовжують нумерацію попередніх рядків, а не почались знову з 1.

    Завдання 5. Свідома помилка прямого імпорту. Спробуйте (на окремій тестовій копії файлу бази, щоб не зіпсувати робочу!) виконати .import CSV-файлу НАПРЯМУ в реальну таблицю-вимір 1 (не в проміжну). Зафіксуйте письмово, що саме сталося — повідомлення про помилку, неправильний розподіл значень по колонках, чи щось інше — і поясніть, чому саме через різну кількість колонок (CSV без id, таблиця з id) це не працює безпосередньо.

    Що здати й оцінюється¶

    Здайте lab_work_15.sql — усі виконані команди (Завдання 1-5) разом з результатами підрахунків; lab_work_15.db — файл бази даних після імпорту CSV; і lab_work_15.md — письмові пояснення до Завдань 1, 3, 4 і 5. Контрольні питання:

    • Чому CSV-файл цієї практики навмисно НЕ містить колонку id — що б сталося, якби спробувати додати її туди самостійно з довільними значеннями?
    • Яка роль DROP TABLE проміжної таблиці в кінці процесу — чи можна просто залишити її в базі "про всяк випадок"?
    • Чим підрахунок COUNT(*) до/після (Завдання 1 і 3) кращий за просто "здається, що імпорт спрацював"?

    Оцінюється правильна структура проміжної таблиці (Завдання 2), точний збіг приросту кількості рядків з кількістю рядків CSV (Завдання 3), і зафіксований результат свідомої помилки прямого імпорту (Завдання 5).

    Підсумок заняття¶

    • Імпортовано 8 нових рядків CSV-файлу свого варіанта в таблицю-вимір 1 через проміжну таблицю, без жодного вигаданого чи вручну набраного значення id.
    • Підтверджено підрахунком COUNT(*), що кількість перенесених рядків точно відповідає кількості рядків вихідного CSV-файлу.
    • На практиці підтверджено, чому прямий імпорт CSV без id у таблицю з колонкою id не працює безпосередньо.
