\# Практична робота №15



\*\*Тема:\*\* Створення індексів та аналіз ефективності запитів



\*\*Виконала:\*\* Вовк Марія, група І-23



\## Мета роботи



Навчитися створювати індекси в SQLite та аналізувати ефективність запитів за допомогою EXPLAIN QUERY PLAN.



\## Завдання 1. Перевірка запиту до створення індексу



Виконала запит для пошуку записів за book\_id.



Результат:



&#x20;   SCAN loans



SQLite виконав повне сканування таблиці loans.



\## Завдання 2. Створення індексу за book\_id



Створила індекс idx\_loans\_book\_id.



Результат:



&#x20;   SEARCH loans USING INDEX idx\_loans\_book\_id (book\_id=?)



Після створення індексу SQLite почав використовувати його для пошуку записів.



\## Завдання 3. Композитний індекс



Створила композитний індекс idx\_loans\_book\_reader за двома стовпцями: book\_id та reader\_id.



До створення композитного індексу використовувався індекс за book\_id.



Після створення отримала результат:



&#x20;   SEARCH loans USING INDEX idx\_loans\_book\_reader (book\_id=? AND reader\_id=?)



Композитний індекс дозволяє виконувати пошук за двома умовами одночасно.



\## Завдання 4. Індекс за датою



Перевірила сортування записів за loan\_date.



До створення індексу:



&#x20;   SCAN loans

&#x20;   USE TEMP B-TREE FOR ORDER BY



Після створення індексу idx\_loans\_loan\_date:



&#x20;   SCAN loans USING INDEX idx\_loans\_loan\_date



Індекс допоміг виконувати сортування за датою без використання тимчасової таблиці.



\## Завдання 5. Видалення індексу



Видалила індекс idx\_loans\_book\_id за допомогою DROP INDEX.



Після видалення перевірила план запиту.



Результат:



&#x20;   SEARCH loans USING INDEX idx\_loans\_book\_reader (book\_id=?)



Також перевірила список індексів. Залишилися idx\_loans\_book\_reader та idx\_loans\_loan\_date.



\## Контрольні питання



\*\*1. Для чого використовується EXPLAIN QUERY PLAN?\*\*



Команда показує, як SQLite виконує запит, які індекси використовує та чи сканує всю таблицю.



\*\*2. Для чого потрібен композитний індекс?\*\*



Композитний індекс створюється за кількома стовпцями та допомагає швидше виконувати запити з умовами за цими стовпцями.



\*\*3. Які недоліки має велика кількість індексів?\*\*



Індекси займають додаткове місце та можуть уповільнювати додавання, змінення й видалення даних, оскільки їх потрібно оновлювати.



\## Висновок



Під час практичної роботи навчилася створювати та видаляти індекси в SQLite. За допомогою EXPLAIN QUERY PLAN порівняла плани виконання запитів до та після створення індексів. Побачила, що індекси допомагають оптимізувати пошук і сортування даних.
