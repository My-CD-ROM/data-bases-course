1. Чим UPDATE ... SET колонка = колонка + 1 відрізняється від UPDATE ... SET колонка = конкретне число?

UPDATE ... SET колонка = колонка + 1 збільшує поточне значення колонки на 1. UPDATE ... SET колонка = конкретне число встановлює для вибраного рядка конкретне значення.

2. Чому NOT NULL/UNIQUE/CHECK перевіряються при UPDATE, а FOREIGN KEY залежить від PRAGMA foreign_keys?

NOT NULL, UNIQUE і CHECK є обмеженнями таблиці, тому SQLite перевіряє їх під час зміни даних. FOREIGN KEY у SQLite перевіряється лише тоді, коли увімкнено PRAGMA foreign_keys = ON.

3. Якби було ON DELETE CASCADE замість RESTRICT?

При ON DELETE CASCADE після видалення автомобіля з таблиці cars автоматично видалилися б усі пов'язані записи з таблиці sales. При ON DELETE RESTRICT видалення автомобіля, на який посилається sales, буде заборонено.

4. Чому DELETE без WHERE небезпечніший за помилку типу або порушення обмеження цілісності?

DELETE без WHERE видаляє всі рядки таблиці. Через це можна випадково видалити всі дані. Помилка типу або порушення обмеження цілісності зазвичай зупиняє операцію та не дозволяє внести некоректні дані.
