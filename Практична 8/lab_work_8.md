# Практична робота 8. Застосування агрегатних функцій

**Варіант 9 — університет / деканат**

## Використані таблиці
Використано базу з попередньої практичної: `university` (студенти), `subjects` (дисципліни), `grades` (журнал оцінок). Структура таблиць не змінювалася. У `grades` зараз 0 записів; її поля мають обмеження `NOT NULL`. Тому приклад із `NULL` для завдання 1 показано на nullable-полі `university.first_name`.

## Завдання 1. COUNT(*) проти COUNT(колонка)
Для студента з `id = 7` значення `first_name` встановлено в `NULL`. Результат:
- `COUNT(*)` = 7 — рахує всі рядки.
- `COUNT(first_name)` = 6 — рахує лише ненульові значення.
Різниця дорівнює одному рядку. У фактовій таблиці `grades` провести таку демонстрацію зараз неможливо: вона порожня, а її колонки `NOT NULL`.

## Завдання 2. SUM і AVG
Для `subjects.credits`:
- `SUM(credits)` = 27 — загальна кількість кредитів усіх дисциплін.
- `AVG(credits)` = 4.5 — середня кількість кредитів на одну дисципліну.

## Завдання 3. MIN/MAX для тексту
Для `subjects.title`:
- `MIN(title)` = **Алгоритми та структури даних**.
- `MAX(title)` = **Програмне забезпечення**.
SQLite порівнює текст за правилами сортування (за замовчуванням — бінарне порівняння кодів символів). Тому вибір визначається порядком символів, а не довжиною назви.

## Завдання 4. Кілька агрегатів над фактовою таблицею
Для `grades` одним запитом обчислено `COUNT(*)`, `COUNT(grade)`, `SUM(grade)`, `AVG(grade)`, `MIN(grade)` та `MAX(grade)`.
- `COUNT(*)` = 0.
- `COUNT(grade)` = 0.
- `SUM(grade)` = None.
- `AVG(grade)` = None.
- `MIN(grade)` = None.
- `MAX(grade)` = None.
Таблиця `grades` порожня, тому `COUNT` повертає 0, а інші агрегати — `NULL`. Це фактичний результат запиту на наданій базі.

## Завдання 5. Агрегат + WHERE
Для групи `ІТ-21`:
- кількість студентів = 3;
- найраніший рік вступу = 2021;
- найпізніший рік вступу = 2021.
Умова `WHERE group_name = 'ІТ-21'` прибирає з розрахунку студентів інших груп, тому агрегати рахуються лише для цієї групи.

## Перевірка SUM для NULL
Запит `SELECT SUM(NULL) FROM subjects;` повернув **None** (`NULL`). Якщо всі значення аргументу `SUM` дорівнюють `NULL`, результат — `NULL`, а не 0 і не помилка.

## Контрольні питання
1. `COUNT(*)` рахує всі рядки, а `COUNT(колонка)` — тільки рядки, де колонка не `NULL`. `COUNT(*)` і `COUNT(id)` зазвичай однакові, бо первинний ключ `id` не може бути `NULL`.
2. Знаменник `AVG` дорівнював би **4**, бо одне з п'яти значень `NULL` і не враховується.
3. `SUM(колонка)` повертає **NULL**, якщо всі значення колонки `NULL`. Це підтверджено окремим запитом.

## Висновок
Застосовано `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`; перевірено вплив `NULL` на агрегатні функції, порівняння тексту в `MIN`/`MAX` та вплив `WHERE` на рядки, що беруть участь у розрахунку.
